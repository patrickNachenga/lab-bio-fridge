================================================================================
                         INTERACTION PATTERNS
================================================================================

USER WORKFLOW 1: View Facility Details
1. User navigates to Facilities page
2. User clicks on a facility row
3. System loads facility details page
4. Overview tab displays by default
5. User sees all facility information

USER WORKFLOW 2: Add a Child
1. User clicks "Add Child" button (Overview or Children tab)
2. Modal form opens
3. User fills in child information:
   - Full name (required)
   - Date of birth (required)
   - Gender (required)
   - Health status (optional)
   - Contact details (optional)
4. User clicks "Add Child" button
5. Form validates input
6. Child is added to facility
7. Success toast appears
8. Children list updates immediately

USER WORKFLOW 3: Assign Staff
1. User clicks "Assign Staff" button (Overview or Staff tab)
2. Modal form opens
3. User fills in staff information:
   - Full name (required)
   - Role (required)
   - Department (required)
   - Phone (required)
   - Email (optional)
4. User clicks "Assign Staff" button
5. Form validates input
6. Staff is assigned to facility
7. Success toast appears
8. Staff list updates immediately

USER WORKFLOW 4: Edit Facility Information
1. User navigates to Settings tab
2. User clicks "Edit" button
3. Facility form becomes editable
4. User modifies desired fields
5. User clicks "Save Changes"
6. Form validates input
7. Facility is updated
8. Success toast appears
9. Edit mode deactivates

USER WORKFLOW 5: Remove Staff or Child
1. User navigates to Staff or Children tab
2. User clicks trash/delete icon
3. Confirmation dialog appears
4. User confirms action
5. Item is removed from facility
6. Success toast appears
7. List updates immediately

USER WORKFLOW 6: Search and Filter
1. User navigates to Children or Staff tab
2. User types in search box
3. List filters in real-time
4. Results update as user types
5. User can clear search to reset
